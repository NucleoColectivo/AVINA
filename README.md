# AVINA — Matriz Transversal V0.2

Prototipo React/Vite sin Supabase para probar el flujo operativo:

**Experiencia → Matriz → Celda → Evidencia → Comentario → Validación → Historial**

Incluye fichas independientes para seis experiencias, 11 variables del Producto 2 del TDR, panel de celda, evidencia vinculada por metadatos/enlaces, comentarios, solicitudes de cambio, estados de validación, historial, simulación de roles, localStorage, CSV e impresión.

Los nombres de experiencias y países son placeholders y deben reemplazarse únicamente con información verificada de las seis iniciativas. V0.2 no implementa autenticación, permisos reales ni almacenamiento persistente de archivos; esas capas corresponden a la etapa Supabase.
